# AI-Powered SOC Analyst Assistant

## Overview

This project automates the analysis of Suricata IDS alerts using Artificial Intelligence.

## Features

- Suricata IDS Integration
- AI-powered Alert Analysis
- Automatic Incident Report Generation
- Nmap Detection
- Custom ICMP Detection

## Technologies Used

- Python
- Suricata IDS
- Ollama
- Llama 3
- Ubuntu
- Kali Linux
- VMware
